# Практическая работа #7: Уровень 2 (Средний / Medium)

## 1. Описание набора данных
В папке вашего варианта (`medium/variant_XX/`) представлены пять CSV-файлов (разделитель — точка с запятой `;`):

* `members.csv` — база зарегистрированных клиентов (150 клиентов):
  * `member_id`, `nickname`, `city`, `email`, `registered_at`, `loyalty_tier`, `balance`.
* `hardware_pcs.csv` — парк компьютеров (30 ПК):
  * `pc_id`, `pc_number`, `zone_name`, `hourly_rate`, `gpu`, `cpu`, `ram_gb`, `status`.
* `game_sessions.csv` — журнал игровых сессий (500 сессий):
  * `session_id`, `member_id` (для анонимов `NULL`), `pc_id`, `game_title`, `session_date`, `hours_played`, `discount_promo`, `total_paid`, `client_rating`.
* `bar_orders.csv` — заказы в баре и буфете (350 заказов):
  * `order_id`, `member_id` (для анонимов `NULL`), `item_name`, `category`, `order_date`, `quantity`, `item_price`, `total_amount`.
* `tournaments.csv` — реестр киберспортивных турниров клуба (7 турниров):
  * `tournament_id` — номер турнира;
  * `tournament_name` — название турнира;
  * `game_title` — дисциплина;
  * `prize_fund` — призовой фонд (руб.);
  * `entry_fee` — регистрационный взнос с игрока (руб.);
  * `start_date` — дата проведения (`YYYY-MM-DD`);
  * `min_rank` — минимальный уровень карты лояльности для допуска.

## 2. Задания к выполнению

### Часть 1. Перенос данных в SQL и аудит 5 таблиц (CSV → SQLite)
1. Загрузите все 5 CSV-файлов в Pandas.
2. Создайте файл базы данных `club_medium.db` через `sqlite3.connect()`.
3. Обязательно включите механизм внешних ключей: `conn.execute("PRAGMA foreign_keys = ON;")`.
4. Создайте 5 таблиц через `CREATE TABLE` с ограничениями целостности.
5. Импортируйте датафреймы в базу методом `.to_sql(..., if_exists='append', index=False)`.
6. Проверьте целостность базы через сводный SQL-запрос `COUNT(*)` к пяти таблицам со сверкой с `len(df)`.

### Часть 2. Скалярные подзапросы в `WHERE`
Все запросы выполняйте через `pd.read_sql_query(query, conn)`.

1. **Сессии дороже среднего чека по конкретной игре:**  
   Найдите сессии по игре `'Dota 2'`, сумма оплаты которых превышает средний чек **строго по этой же игре**:  
   ```sql
   WHERE game_title = 'Dota 2' 
     AND total_paid > (SELECT AVG(total_paid) FROM game_sessions WHERE game_title = 'Dota 2')
   ```
   Выведите `session_id`, `game_title`, `hours_played`, `total_paid`. Отсортируйте по сумме чека по убыванию.

### Часть 3. Множественные подзапросы (`IN` и `NOT IN`)
1. **Игроки турнирных дисциплин (`IN`):**  
   Найдите клиентов из `members`, которые запускали на компьютерах игры, включенные в официальный турнирный реестр клуба (`tournaments`). Список турнирных дисциплин получите через подзапрос к `tournaments`.
2. **Клиенты без покупок напитков (`NOT IN` с защитой от `NULL`):**  
   Найдите клиентов, которые ни разу не покупали в баре позиции из категории `'Напитки'`. Обязательно исключите `NULL` во внутреннем подзапросе (`WHERE member_id IS NOT NULL`).

### Часть 4. Коррелированные подзапросы в `WHERE` (Сравнение внутри группы)
1. **Аномально длинные сессии по конкретным ПК:**  
   Найдите сессии, длительность которых (`hours_played`) строго превышает среднюю длительность сессий **на данном конкретном компьютере**:  
   ```sql
   WHERE s1.hours_played > (
       SELECT AVG(s2.hours_played) 
       FROM game_sessions s2 
       WHERE s2.pc_id = s1.pc_id
   )
   ```
2. **Крупные барные заказы внутри товарных категорий:**  
   Найдите заказы в баре, сумма которых (`total_amount`) превышает средний чек **внутри соответствующей категории товаров** (`WHERE b1.category = b2.category`).

### Часть 5. Предикаты существования (`EXISTS` и `NOT EXISTS`)

2. **Турниры, подкрепленные игровой активностью (`EXISTS`):**

### Часть 6. Скалярные подзапросы в `SELECT` (Аналитика «Клиент 360»)

### Часть 8. Кросс-табличная аналитика и операции над множествами (5 таблиц)
