# Практическая работа #7: Уровень 1 (Базовый / Easy)

## 1. Описание набора данных
В папке вашего варианта (`easy/variant_XX/`) представлены четыре CSV-файла (разделитель — точка с запятой `;`):

* `members.csv` — база зарегистрированных клиентов:
  * `member_id` — уникальный ID клиента (целое число);
  * `nickname` — игровой никнейм;
  * `city` — город регистрации;
  * `email` — электронная почта (часть значений `NULL`);
  * `registered_at` — дата регистрации (`YYYY-MM-DD`);
  * `loyalty_tier` — уровень карты лояльности (`Bronze`, `Silver`, `Gold`, `Platinum`);
  * `balance` — остаток депозита на клубном счете (руб.).

* `hardware_pcs.csv` — каталог компьютеров:
  * `pc_id` — идентификатор рабочей станции;
  * `pc_number` — номер ПК (`PC-01`, `PC-02`...);
  * `zone_name` — зона посадки (`Standard`, `Bootcamp`, `VIP`, `PS5`);
  * `hourly_rate` — тариф за час аренды (руб.);
  * `gpu` — видеокарта;
  * `cpu` — процессор;
  * `ram_gb` — объем ОЗУ;
  * `status` — эксплуатационный статус (`Active`, `Maintenance`, `Reserved`).

* `game_sessions.csv` — журнал игровых сессий:
  * `session_id` — номер сессии;
  * `member_id` — ID игрока (внешний ключ к `members`; для анонимов `NULL`);
  * `pc_id` — номер занятого ПК (внешний ключ к `hardware_pcs`);
  * `game_title` — запущенная игра;
  * `session_date` — дата и время игры (`YYYY-MM-DD HH:MM:SS`);
  * `hours_played` — продолжительность сессии в часах;
  * `discount_promo` — флаг скидки (1 / 0);
  * `total_paid` — фактически оплаченная сумма (руб.);
  * `client_rating` — оценка сервиса (от 1 до 5 звезд, часть `NULL`).

* `bar_orders.csv` — заказы в баре и буфете клуба:
  * `order_id` — уникальный номер заказа;
  * `member_id` — ID клиента (внешний ключ к `members`; для анонимов `NULL`);
  * `item_name` — название позиции (напиток, снек, сэндвич, мерч);
  * `category` — товарная категория (`Напитки`, `Снеки`, `Горячее`, `Мерч`);
  * `order_date` — дата и время заказа (`YYYY-MM-DD HH:MM:SS`);
  * `quantity` — количество купленных единиц;
  * `item_price` — цена за единицу товара (руб.);
  * `total_amount` — сумма чека (руб.).

## 2. Задания к выполнению

### Часть 1. Перенос данных в SQL и аудит 4 таблиц (CSV → SQLite)
1. Загрузите файлы `members.csv`, `hardware_pcs.csv`, `game_sessions.csv` и `bar_orders.csv` в Pandas.
2. Создайте файл базы данных `club_easy.db` через `sqlite3.connect()`.
3. Обязательно включите контроль внешних ключей: `conn.execute("PRAGMA foreign_keys = ON;")`.
4. Создайте 4 таблицы через `CREATE TABLE` с ограничениями `PRIMARY KEY`, `NOT NULL` и внешними ключами (`FOREIGN KEY`).
5. Загрузите данные в SQLite методом `.to_sql(..., if_exists='append', index=False)`.
6. Проведите валидационный аудит количества строк во всех четырех таблицах через SQL-запрос `COUNT(*)` и сверку с `len(df)`.

---

### Часть 2. Скалярные подзапросы в `WHERE` (сравнение с вычисленным числом)
Все запросы выполняйте через `pd.read_sql_query(query, conn)`.

1. **Сессии с оплатой выше среднего чека клуба:**  
   Найдите все сессии, сумма оплаты по которым (`total_paid`) строго превышает средний чек по всей таблице `game_sessions`.  
   Выведите `session_id`, `game_title`, `hours_played`, `total_paid`. Отсортируйте по чеку по убыванию.
2. **Компьютеры с максимальной стоимостью часа:**  
   Найдите ПК из `hardware_pcs`, почасовой тариф которых равен максимальному тарифу клуба (`hourly_rate = (SELECT MAX(hourly_rate) FROM hardware_pcs)`).

---

### Часть 3. Множественные подзапросы (`IN` и `NOT IN`)
1. **Поклонники шутеров (`IN`):**  
   Найдите зарегистрированных клиентов (`member_id`, `nickname`, `city`, `loyalty_tier`), которые хотя бы один раз запускали игру `'Counter-Strike 2'`.
2. **Клиенты без заказов в баре (`NOT IN` с защитой от `NULL`):**  
   Найдите зарегистрированных клиентов, которые ни разу ничего не покупали в баре клуба.  
   *Важный намек:* в `bar_orders` есть анонимные заказы (`member_id IS NULL`). Обязательно добавьте во внутренний запрос `WHERE member_id IS NOT NULL`, иначе из-за трехзначной логики SQL весь запрос вернет 0 строк!

---

### Часть 4. Коррелированные подзапросы в `WHERE`
1. **Сессии дольше средней на конкретном компьютере:**  
   Найдите сессии, длительность которых (`hours_played`) превышает среднюю длительность сессий **на том же самом компьютере**:  
   ```sql
   WHERE s1.hours_played > (
       SELECT AVG(s2.hours_played) 
       FROM game_sessions s2 
       WHERE s2.pc_id = s1.pc_id
   )
   ```
   Выведите `session_id`, `pc_id`, `game_title`, `hours_played`, `total_paid`.

---

### Часть 5. Предикаты существования (`EXISTS` и `NOT EXISTS`)
1. **Любители горячего питания (`EXISTS`):**  
   Найдите зарегистрированных клиентов, у которых есть хотя бы один заказ в категории `'Горячее'` в таблице `bar_orders`.
2. **Простаивающее оборудование (`NOT EXISTS`):**  
   Найдите компьютеры из `hardware_pcs`, на которых за все время не зафиксировано ни одной игровой сессии в `game_sessions`.

---

### Часть 6. Подзапросы в секции `SELECT` (Базовый профиль клиента)
1. **Клиентская сводка трат:**  
   Сформируйте срез по клиентам: `member_id`, `nickname`, `loyalty_tier`. Для каждого клиента с помощью независимых скалярных подзапросов в `SELECT` вычислите:
   * число сыгранных сессий: `(SELECT COUNT(*) FROM game_sessions s WHERE s.member_id = m.member_id) AS sessions_count`;
   * сумму расходов в баре: `(SELECT IFNULL(SUM(total_amount), 0) FROM bar_orders b WHERE b.member_id = m.member_id) AS bar_spend`.  
   Отсортируйте по сумме расходов в баре по убыванию и выведите топ-10.

---

### Часть 7. Подзапросы в секции `FROM` (Агрегаты над агрегатами)
1. **Среднее число сессий на одного игрока:**  
   Внутренним запросом в `FROM` сгруппируйте `game_sessions` по `member_id` (исключая `NULL`) и посчитайте количество сессий каждого игрока. Внешним запросом найдите среднее, минимальное и максимальное число сессий.
2. **Средний суммарный барный чек гостя:**  
   Внутренним запросом посчитайте сумму трат каждого клиента в баре (`SUM(total_amount)`). Внешним запросом найдите средний LTV гостя по барным покупкам (`ROUND(AVG(total_bar_spend), 2)`).

### Часть 8. Операции над множествами (`UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT`)
1. **Сравнение `UNION` и `UNION ALL`:**  
   Объедините список ID клиентов из `game_sessions` со списком ID клиентов из `bar_orders` через `UNION`, а затем через `UNION ALL`. Сравните число строк.
2. **Универсальные гости (`INTERSECT`):**  
   Найдите пересечение ID клиентов, которые **и** играли на ПК, **и** совершали покупки в баре. Выведите их никнеймы и города.
3. **Чистые геймеры (`EXCEPT`):**  
   Найдите клиентов, которые играли на ПК, но **ни разу** не воспользовались баром клуба.
