# Практическая работа #4: Уровень 1 (Базовый / Easy)

## 1. Описание набора данных
В папке вашего варианта (`easy/variant_XX/`) представлены два CSV-файла (разделитель — точка с запятой `;`):

* `members.csv` — база постоянных клиентов компьютерного клуба:
  * `member_id` — уникальный код клиента;
  * `nickname` — игровой псевдоним (никнейм);
  * `city` — город регистрации;
  * `email` — адрес электронной почты (у части гостей отсутствует — значение `NULL`);
  * `registered_at` — дата регистрации клубного аккаунта (формат `YYYY-MM-DD`);
  * `loyalty_tier` — уровень карты лояльности (`Bronze`, `Silver`, `Gold`, `Platinum`);
  * `balance` — остаток денежных средств на клубном счете (руб.).

* `hardware_pcs.csv` — парк игрового оборудования:
  * `pc_id` — номер рабочего места;
  * `zone_name` — игровая зона (`Standard`, `Bootcamp`, `VIP`, `PS5`);
  * `hourly_rate` — почасовой тариф аренды (руб./час);
  * `gpu` — установленный графический ускоритель;
  * `cpu` — центральный процессор;
  * `ram_gb` — объем оперативной памяти (ГБ);
  * `status` — эксплуатационный статус (`Active` — в строю, `Maintenance` — на техобслуживании).

---

## 2. Задания к выполнению

### Часть 1. Перенос данных в SQL (Pandas → SQLite)
1. Считайте оба CSV-файла в Pandas DataFrame.
2. Создайте файл базы данных SQLite `club_easy.db` с помощью `sqlite3.connect()`.
3. Экспортируйте датафреймы в таблицы `members` и `hardware_pcs` методом `.to_sql()` с параметрами `if_exists='replace'` и `index=False`.
4. Сделайте проверочный системный запрос для вывода списка созданных таблиц:
   ```sql
   SELECT name FROM sqlite_master WHERE type='table';
   ```

---

### Часть 2. Базовые выборки оборудования (`hardware_pcs`)
Все запросы выполняйте через `pd.read_sql_query(query, conn)`.

1. **Диапазон стоимости (`BETWEEN`):**
   * Выберите все ПК с тарифом от 200 до 350 руб./час.
   * Выведите столбцы `pc_id`, `zone_name`, `hourly_rate`, `gpu`.
2. **Фильтрация по списку значений (`IN`):**
   * Выведите список ПК, расположенных в премиальных зонах `'VIP'` и `'Bootcamp'`.
   * Исключите ПК, находящиеся на техобслуживании (`status = 'Active'`).
3. **Отрицание и строгое равенство (`!=`, `=`):**
   * Выведите компьютеры зоны `'Standard'`, у которых установлена видеокарта, отличная от `'GTX 1660 Super'`.
4. **Топ дорогих машин (`ORDER BY`, `LIMIT`):**
   * Выведите топ-3 самых дорогих ПК клуба по величине часового тарифа.
5. **Топ доступных рабочих мест:**
   * Выведите 5 самых доступных ПК со статусом `'Active'`, отсортированных по возрастанию стоимости часа.

---

### Часть 3. Базовые выборки клиентов (`members`)

1. **Проверка пропущенных значений (`IS NULL` / `IS NOT NULL`):**
   * Выведите список клиентов, у которых в базе не указан email (`IS NULL`).
   * Отдельным запросом выведите общее число клиентов без email и их процент от общего размера базы.
2. **Фильтрация по почтовому домену и статусу:**
   * Выведите клиентов с заполненным адресом почты (`IS NOT NULL`), проживающих в городах `'Москва'` или `'Санкт-Петербург'` (`IN`), у которых статус карты равен `'Gold'` или `'Platinum'`.
3. **Поиск по началу никнейма (`LIKE`):**
   * Найдите игроков, никнейм которых начинается на букву `'S'` или на букву `'C'`.
4. **Топ клиентов по депозиту:**
   * Выберите топ-5 клиентов клуба по сумме остатка на балансе (`balance`), отсортировав их по убыванию депозита.
   * Выведите `member_id`, `nickname`, `loyalty_tier` и `balance`.
