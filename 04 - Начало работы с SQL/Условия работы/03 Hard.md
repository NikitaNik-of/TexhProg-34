# Практическая работа #4: Уровень 3 (Продвинутый / Hard)

## 1. Описание набора данных
В папке вашего варианта (`hard/variant_XX/`) представлены четыре CSV-файла (разделитель — точка с запятой `;`):

* `members.csv` — реестр зарегистрированных игроков клуба:
  * `member_id` — идентификатор клиента;
  * `nickname` — игровой никнейм;
  * `city` — город;
  * `email` — электронная почта (часть значений `NULL`);
  * `registered_at` — дата регистрации (`YYYY-MM-DD`);
  * `loyalty_tier` — уровень карты лояльности (`Bronze`, `Silver`, `Gold`, `Platinum`);
  * `balance` — депозит на балансе (руб.).

* `hardware_pcs.csv` — парковый реестр компьютеров:
  * `pc_id` — номер ПК;
  * `zone_name` — зона посадки (`Standard`, `Bootcamp`, `VIP`, `PS5`);
  * `hourly_rate` — почасовой тариф (руб.);
  * `gpu` — видеокарта;
  * `cpu` — процессор;
  * `ram_gb` — оперативная память (ГБ);
  * `status` — статус оборудования (`Active` / `Maintenance`).

* `game_sessions.csv` — хронометраж игровых сессий:
  * `session_id` — номер сессии;
  * `member_id` — ID игрока (`NULL` для анонимных визитов);
  * `pc_id` — номер занятого ПК;
  * `game_title` — запущенная игра;
  * `session_date` — дата и точное время старта (`YYYY-MM-DD HH:MM:SS`);
  * `hours_played` — сыгранные часы;
  * `discount_promo` — флаг скидки (1 / 0);
  * `total_paid` — оплата аренды ПК с учетом скидки (руб.);
  * `client_rating` — оценка сессии от 1 до 5 (`NULL` при отсутствии отзыва).

* `bar_purchases.csv` — детальные транзакции бара во время игровых сессий:
  * `purchase_id` — уникальный номер чека продажи (`PUR-XXXX`);
  * `session_id` — номер игровой сессии, к которой привязана покупка;
  * `item_name` — наименование товара;
  * `category` — категория товара (`Energy Drinks`, `Snacks`, `Hot Food`, `Hot Drinks`);
  * `price` — цена за единицу товара (руб.);
  * `quantity` — количество единиц в чеке;
  * `total_price` — итоговая стоимость позиции чека (руб.);
  * `payment_type` — способ оплаты (`Card`, `Account_Balance`, `Cash`).
