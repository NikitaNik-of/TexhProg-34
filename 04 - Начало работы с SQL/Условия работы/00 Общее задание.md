# Практическая работа #4: Перенос данных в SQL и базовые выборки данных

## 1. Цель работы
Цель работы — освоить двухстороннюю связку между аналитической библиотекой Pandas и реляционной СУБД SQLite:
1. Научиться импортировать плоские таблицы из файлов CSV в таблицы базы данных SQLite средствами метода `to_sql()`.
2. Освоить базовый синтаксис декларативных запросов `SELECT` с фильтрацией строк (`WHERE`), сортировкой (`ORDER BY`) и ограничением выборки (`LIMIT` / `OFFSET`).
3. Научиться возвращать результаты выполнения SQL-запросов обратно в структуры Pandas (`pd.read_sql_query`) для последующего анализа и визуализации.

---

## 2. Организация данных и уровни сложности

Данные описывают процессы управления киберспортивным компьютерным клубом: регистрацию клиентов, учет парка компьютеров, проведение игровых сессий и продажи в клубном баре.

Практическая работа разделена на три уровня сложности:
* **Уровень 1 (Easy / Базовый):** перенос 2 справочников (`members.csv` и `hardware_pcs.csv`). Освоение базового `SELECT`, фильтрации по диапазонам (`BETWEEN`), спискам (`IN`), проверки отсутствующих контактов (`IS NULL`) и поиска топов (`ORDER BY`, `LIMIT`).
* **Уровень 2 (Medium / Средний):** перенос 3 таблиц (`members.csv`, `hardware_pcs.csv`, `game_sessions.csv`). Освоение строковых шаблонов (`LIKE`), составных логических условий (`AND`, `OR`, `NOT`), многоуровневой сортировки и постраничного вывода (`OFFSET`).
* **Уровень 3 (Hard / Продвинутый):** перенос 4 таблиц (`members.csv`, `hardware_pcs.csv`, `game_sessions.csv`, `bar_purchases.csv`). Работа со схемами DDL и типами данных (`PRAGMA table_info`), фильтрация дат и времени в формате ISO через функцию `strftime()`, составные бизнес-выборки и аналитическое сравнение производительности и лаконичности Pandas vs SQL.

## 3. Лекторский минимум (допустимый набор функций)

В рамках работы отрабатывается строго очерченный инструментарий:

### Python ↔ SQLite
* `sqlite3.connect(database_path)` — создание соединения с файлом БД;
* `df.to_sql(name, con, if_exists='replace', index=False)` — экспорт таблицы в SQL;
* `pd.read_sql_query(sql, con)` — выполнение SQL-запроса с возвратом DataFrame;
* `conn.close()` — закрытие соединения с базой.

### Ядро синтаксиса SQL
* Проекция: `SELECT`, `SELECT DISTINCT`, алиасы `AS`;
* Фильтрация `WHERE`:
  * Операторы сравнения: `=`, `!=` (`<>`), `<`, `>`, `<=`, `>=`;
  * Диапазоны: `BETWEEN a AND b`;
  * Списки: `IN (val1, val2, ...)`, `NOT IN (...)`;
  * Строковые шаблоны: `LIKE 'шаблон'` (маски `%` — любая строка, `_` — один символ);
  * Проверка пропусков: `IS NULL`, `IS NOT NULL`;
  * Логика: `AND`, `OR`, `NOT`, круглые скобки `(...)`;
* Сортировка: `ORDER BY col1 [ASC|DESC], col2 [ASC|DESC]`;
* Ограничение выборки: `LIMIT count [OFFSET skip]`;
* Даты: строковое сравнение ISO-дат (`YYYY-MM-DD`) и функция `strftime(format, date_col)`.

## 4. Общие требования к оформлению

1. Работа выполняется в индивидуальном блокноте Jupyter (`.ipynb`).
2. Для каждого вопроса задания создается отдельная ячейка Markdown с формулировкой задачи и отдельная ячейка кода с SQL-запросом.
3. Текст запроса оформляется внутри многострочной строки Python (`query = """ SELECT ... """`).
4. Результат запроса выводится на экран в виде отформатированного DataFrame.
5. После каждого запроса дается краткий вывод на 1–2 предложения по полученным данным.
