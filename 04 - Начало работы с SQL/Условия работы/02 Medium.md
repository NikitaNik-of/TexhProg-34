# Практическая работа #4: Уровень 2 (Средний / Medium)

## 1. Описание набора данных
В папке вашего варианта (`medium/variant_XX/`) представлены три CSV-файла (разделитель — точка с запятой `;`):

* `members.csv` — база зарегистрированных клиентов:
  * `member_id` — уникальный номер аккаунта;
  * `nickname` — игровой никнейм;
  * `city` — город;
  * `email` — электронная почта (часть значений `NULL`);
  * `registered_at` — дата регистрации (`YYYY-MM-DD`);
  * `loyalty_tier` — уровень лояльности (`Bronze`, `Silver`, `Gold`, `Platinum`);
  * `balance` — баланс клубного депозита (руб.).

* `hardware_pcs.csv` — каталог компьютеров:
  * `pc_id` — идентификатор ПК;
  * `zone_name` — зона посадки (`Standard`, `Bootcamp`, `VIP`, `PS5`);
  * `hourly_rate` — тариф за час игры (руб.);
  * `gpu` — модель видеокарты;
  * `cpu` — модель процессора;
  * `ram_gb` — оперативная память (ГБ);
  * `status` — эксплуатационный статус (`Active` / `Maintenance`).

* `game_sessions.csv` — журнал игровых сессий:
  * `session_id` — уникальный номер сессии;
  * `member_id` — ID игрока (для анонимных визитов без клубной карты значение равно `NULL`);
  * `pc_id` — номер занятого ПК;
  * `game_title` — основная запущенная игра;
  * `session_date` — дата и время начала игры (`YYYY-MM-DD HH:MM:SS`);
  * `hours_played` — продолжительность сессии в часах;
  * `discount_promo` — флаг скидки по промокоду (1 — скидка 10%, 0 — без скидки);
  * `total_paid` — фактическая оплата аренды ПК с учетом скидки (руб.);
  * `client_rating` — оценка сервиса от 1 до 5 звезд (часть клиентов не оставила отзыв — значение `NULL`).

## 2. Задания к выполнению

### Часть 1. Перенос данных и аудит целостности (Pandas → SQLite)
1. Загрузите файлы `members.csv`, `hardware_pcs.csv` и `game_sessions.csv` в Pandas.
2. Создайте файл базы данных `club_medium.db` через `sqlite3.connect()`.
3. Экспортируйте датафреймы в одноименные таблицы SQLite с параметром `index=False`.
4. **Аудит количества записей:**
   * Напишите SQL-запрос с `COUNT(*)`, возвращающий точное число строк в каждой из трех таблиц.
   * Сверьте результат с длиной исходных DataFrame в Pandas (`len(df)`).

---

### Часть 2. Текстовый поиск и шаблоны (`LIKE`)
1. **Поколения видеокарт:**
   * Найдите все ПК, оснащенные видеокартами современного семейства RTX 40-й серии (`gpu LIKE 'RTX 40%'`).
   * Выведите `pc_id`, `zone_name`, `gpu`, `hourly_rate`.
2. **Почтовые сервисы клиентов:**
   * Выберите всех клиентов, у которых почтовый ящик зарегистрирован на доменах `@mail.ru` или `@yandex.ru`.
3. **Поиск по названию игры:**
   * Найдите все игровые сессии, в названии игры которых встречается слово `'Strike'` или `'Cyber'` (без учета регистра или по точной маске).
   * Выведите `session_id`, `game_title`, `session_date`, `hours_played`.

---

### Часть 3. Многоуровневая сортировка (`ORDER BY`)
1. **Зонирование и тарифы:**
   * Отсортируйте список всех ПК сначала по названию зоны (`zone_name ASC`), а внутри каждой зоны — по убыванию стоимости часа (`hourly_rate DESC`).
2. **Хронология и длительность сессий:**
   * Выберите 10 последних сыгранных сессий: сортировка по дате от самых свежих к старым (`session_date DESC`), а при совпадении даты — по убыванию времени игры (`hours_played DESC`).

---

### Часть 4. Постраничный вывод и пагинация (`LIMIT` + `OFFSET`)
1. **Имитация веб-каталога компьютеров:**
   * Выведите первую страницу активных ПК (5 машин с наименьшим тарифом): `LIMIT 5 OFFSET 0`.
   * Выведите вторую страницу каталога (следующие 5 машин по возрастанию тарифа): `LIMIT 5 OFFSET 5`.
2. **Рекордные сессии в Dota 2:**
   * Найдите 2-ю и 3-ю по продолжительности сессии в игре `'Dota 2'` (подсказка: пропустить 1 самую длинную сессию и взять 2 следующие через `LIMIT 2 OFFSET 1`).

---

### Часть 5. Составные бизнес-условия (`AND`, `OR`, `NOT`, скобки)
1. **Анализ анонимного потока:**
   * Найдите сессии незарегистрированных гостей (`member_id IS NULL`), которые провели в клубе 3 и более часов (`hours_played >= 3`) без применения промокода (`discount_promo = 0`).
2. **Целевая аудитория турниров:**
   * Выберите клиентов из городов `'Москва'` или `'Санкт-Петербург'`, имеющих статус карты `'Gold'` или `'Platinum'` и баланс на счете не менее 1500 рублей.
3. **Сессии с максимальной удовлетворенностью:**
   * Выберите сессии продолжительностью от 4 часов, где клиент оставил наивысшую оценку (`client_rating = 5`).
   * Отсортируйте их по сумме оплаты (`total_paid DESC`).
