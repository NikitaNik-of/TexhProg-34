# Практическая работа #3: Уровень 1 (Базовый / Easy)

## Описание набора данных
В папке вашего варианта (`easy/variant_XX/`) представлены три CSV-файла (разделитель — точка с запятой `;`):
* `sessions.csv` — журнал игровых сессий:
  * `session_id` — уникальный идентификатор сессии;
  * `user_id` — идентификатор клиента (для анонимных визитов значение отсутствует);
  * `pc_id` — идентификатор компьютера;
  * `date` — дата и время начала сессии;
  * `hours_played` — длительность сессии в часах;
  * `discount_promo` — применение скидочного промокода (1 — скидка 10% на аренду ПК, 0 — без скидки).
* `users.csv` — справочник зарегистрированных клиентов:
  * `user_id` — уникальный идентификатор клиента;
  * `birth_date` — дата рождения;
  * `gender` — пол клиента (`M` / `F`);
  * `loyalty_tier` — уровень карты лояльности (`Bronze`, `Silver`, `Gold`, `Platinum`).
* `pcs.csv` — реестр оборудования компьютерного клуба:
  * `pc_id` — уникальный номер компьютера;
  * `pc_zone` — зона посадки (`Standard`, `Bootcamp`, `VIP`, `PS5`);
  * `hourly_rate` — базовая стоимость одного часа аренды (руб.);
  * `gpu` — установленная видеокарта или игровая платформа.

## Задания к выполнению

### 1. Первичная проверка структуры и ключей
1. Загрузите файлы варианта и определите их размерности.
2. Проверьте уникальность первичных ключей в справочниках `users` и `pcs`.

### 2. Исследование данных с помощью 4 типов объединений
1. **Внутреннее соединение (`inner`):**
   * Сопоставьте журнал сессий со справочником клиентов, оставив только подтвержденные сессии зарегистрированных пользователей.
   * Рассчитайте количество сессий и среднюю продолжительность игры для каждого уровня карты лояльности.
   * Сделайте вывод, клиенты какого уровня лояльности проводят в клубе больше всего времени за одну сессию.
2. **Левое внешнее соединение (`left`):**
   * Объедините сессии и справочник клиентов так, чтобы сохранить абсолютно все сессии из журнала.
   * Определите количество анонимных визитов (без клубного аккаунта) и их процентную долю в общем потоке посещений.
   * Сравните среднюю длительность игры постоянных клиентов клуба и анонимных гостей.
3. **Правое внешнее соединение (`right`):**
   * Объедините сессии и реестр компьютеров так, чтобы сохранить все единицы оборудования.
   * Выявите компьютеры, на которых за весь отчетный период не было зафиксировано ни одной сессии.
   * Выведите перечень простаивающих машин с указанием их зон и видеокарт.
4. **Полное внешнее соединение (`outer`):**
   * Сопоставьте журнал сессий и справочник клиентов для сквозного аудита клиентской базы.
   * Определите число зарегистрированных клиентов, которые ни разу не посетили клуб за отчетный период, и их долю от общего размера базы.

### 3. Сквозной анализ выручки по зонам клуба
1. Объедините данные сессий со справочниками клиентов и компьютеров.
2. Рассчитайте фактическую стоимость аренды ПК за каждую сессию с учетом скидки по промокоду.
3. Сравните игровые зоны клуба (`pc_zone`): для каждой зоны определите общее число сыгранных часов, суммарную выручку и средний чек одной сессии.
4. Определите, в каких зонах клуба чаще всего играют клиенты с разным уровнем карты лояльности (`loyalty_tier`).
