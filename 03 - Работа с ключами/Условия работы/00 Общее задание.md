# Практическая работа #3: Реляционные связи и объединение данных в Pandas

## 1. Цель работы
Цель работы — освоить принципы реляционной организации данных, практическую работу с первичными и внешними ключами, применение всех четырех типов объединений таблиц (`inner`, `left`, `right`, `outer`), обработку полуструктурированных атрибутов и проведение бизнес-аналитики по связанным датасетам.

---

## 2. Организация данных и варианты
Практическая работа разделена на три уровня сложности:
* **Уровень 1 (Easy / Базовый):** три готовые связанные таблицы (`sessions.csv`, `users.csv`, `pcs.csv`). Основной упор — понимание семантики всех четырех типов объединения, сопоставление сущностей и выявление аномалий.
* **Уровень 2 (Medium / Средний):** частично денормализованные данные (`sessions_with_specs.csv`, `users.csv`). Основной упор — декомпозиция сущностей из JSON-словаря, аудит ссылочной целостности («битые» ключи) и аналитика предпочтений гостей.
* **Уровень 3 (Hard / Продвинутый):** вложенные массивы транзакций бара (`sessions_with_orders.csv`, `users.csv`, `bar_catalog.csv`). Основной упор — нормализация связи 1:N из JSON-массива в отдельную таблицу фактов, построение схемы «Звезда», маржинальный анализ и сопоставление поведения игроков.

Для каждого уровня сложности подготовлено 20 индивидуальных вариантов данных:
* `easy/variant_01/` ... `variant_20/`
* `medium/variant_01/` ... `variant_20/`
* `hard/variant_01/` ... `variant_20/`

Номер варианта определяется преподавателем или порядковым номером в академическом журнале.

1. Работа выполняется в индивидуальном Jupyter Notebook (`.ipynb`).
2. Код должен быть структурирован по разделам задания с краткими текстовыми выводами (Markdown) по каждому исследуемому вопросу.
3. Перед объединением таблиц обязательна валидация ключей связывания.
4. В обязательном порядке должны быть продемонстрированы и содержательно проинтерпретированы все 4 типа объединения данных.
5. Результаты расчетов должны сопровождаться наглядными таблицами или сводками.
