# Практическая работа #6: Уровень 1 (Базовый / Easy)

## 1. Описание набора данных
В папке вашего варианта (`easy/variant_XX/`) представлены два CSV-файла (разделитель — точка с запятой `;`):

* `members.csv` — база зарегистрированных гостей клуба:
  * `member_id` — уникальный номер клубной карты (целое число);
  * `nickname` — игровой никнейм;
  * `city` — город регистрации;
  * `email` — адрес электронной почты (у части гостей отсутствует — `NULL`);
  * `registered_at` — дата регистрации (`YYYY-MM-DD`);
  * `loyalty_tier` — уровень карты лояльности (`Bronze`, `Silver`, `Gold`, `Platinum`);
  * `balance` — остаток депозита на клубном счете (руб.).

* `game_sessions.csv` — журнал игровых сессий:
  * `session_id` — номер сессии;
  * `member_id` — ID игрока (внешний ключ к `members`);
  * `game_title` — запущенная игра;
  * `session_date` — дата и время начала игры (`YYYY-MM-DD HH:MM:SS`);
  * `hours_played` — длительность аренды в часах;
  * `discount_promo` — флаг скидки (1 — со скидкой 10%, 0 — без скидки);
  * `total_paid` — фактически оплаченная сумма (руб.);
  * `client_rating` — оценка сервиса от 1 до 5 звезд (часть клиентов не оставила отзыв — `NULL`).

## 2. Задания к выполнению

### Часть 1. Подготовка базы данных (CSV → SQLite)
1. Считайте оба CSV-файла через Pandas (`pd.read_csv(..., sep=';')`).
2. Создайте файл базы данных `club_easy.db` через `sqlite3.connect()`.
3. Создайте таблицы `members` и `game_sessions` через `CREATE TABLE` с указанием типов данных и первичных/внешних ключей (`FOREIGN KEY (member_id) REFERENCES members(member_id)`).
4. Загрузите датафреймы в таблицы методом `.to_sql(..., if_exists='append', index=False)`.
5. Проверьте целостность: сравните `COUNT(*)` из обеих таблиц с длинами исходных датафреймов в Pandas (`len(df)`).

### Часть 2. Базовые агрегаты по всей таблице
Все запросы выполняйте через `pd.read_sql_query(query, conn)`.

1. **Общая статистика клуба:**  
   Одним SQL-запросом к `game_sessions` рассчитайте:
   * общее число проведенных сессий (`COUNT(*)`);
   * суммарную выручку клуба (`SUM(total_paid)`);
   * среднюю продолжительность одной сессии в часах (`AVG(hours_played)`);
   * минимальный и максимальный чек за сессию (`MIN(total_paid)`, `MAX(total_paid)`).
2. **Исследование пропущенных отзывов (`NULL`):**  
   * Сравните результат `COUNT(*)` и `COUNT(client_rating)` в таблице сессий.  
   * *Намек к размышлению:* почему эти два числа различаются? Посчитайте разницу — сколько именно гостей воздержались от выставления оценки?
3. **Оценки «отлично»:**  
   Посчитайте количество сессий, где клиенты поставили наивысшую оценку 5 звезд, и среднюю длительность таких сессий.

### Часть 3. Группировка данных (`GROUP BY`)
1. **Популярность игр:**  
   Сгруппируйте сессии по названию игры (`game_title`). Для каждой игры выведите:
   * название игры;
   * количество запусков;
   * суммарное число наигранных часов;
   * среднюю оценку игроков (`AVG(client_rating)`), округленную до 2 знаков.  
   Отсортируйте результат по числу запусков от самых популярных к редким.
2. **География клиентской базы:**  
   Сгруппируйте клиентов из таблицы `members` по городам (`city`). Для каждого города выведите число клиентов и суммарный остаток денег на депозитах.
3. **Распределение по длительности:**  
   Сгруппируйте сессии по числу часов (`hours_played`) и посчитайте, сколько сессий приходится на каждый интервал времени.

### Часть 4. Фильтрация вычисленных групп (`HAVING`)
1. **Хиты клуба:**  
   На основе группировки по играм оставьте только те игры, в которые сыграли **более 25 раз**.
2. **Высокооцененные игры:**  
   Найдите игры со средней оценкой **не ниже 4.0** баллов.
3. **Города с высоким депозитом:**  
   По таблице клиентов выведите города, где суммарный депозит пользователей превышает **25 000 рублей**.
4. **Сквозной фильтр (WHERE + GROUP BY + HAVING):**  
   Рассмотрите сессии, оформленные **со скидкой** (`discount_promo = 1`). Сгруппируйте их по играм и оставьте только те игры, суммарная выручка по которым со скидками превысила **3 000 рублей**.

### Часть 5. Соединение таблиц (`JOIN`)
1. **Сессии с именами клиентов (`INNER JOIN`):**  
   Соедините таблицы `game_sessions` и `members`. Выведите `session_id`, `nickname`, `city`, `game_title`, `hours_played`, `total_paid`. Отсортируйте по сумме оплаты (`total_paid DESC`) и покажите топ-10 самых дорогих сессий.
2. **Поиск «спящих» клиентов (`LEFT JOIN` + `IS NULL`):**  
   Найдите зарегистрированных гостей, которые за все время не сыграли **ни одной сессии**.  
   *Намек:* сделайте `LEFT JOIN` от `members` к `game_sessions` и отфильтруйте строки, где первичный ключ сессии равен `NULL`. Выведите никнейм, город и баланс таких гостей.
3. **Индивидуальные траты гостей (`JOIN` + `GROUP BY`):**  
   Для каждого клиента посчитайте: общее количество сыгранных сессий и суммарную сумму оплат. Выведите никнейм клиента, уровень карты (`loyalty_tier`), количество сессий и сумму трат.
4. **Клубные завсегдатаи (`JOIN` + `GROUP BY` + `HAVING`):**  
   Используя предыдущий запрос, оставьте только тех клиентов, которые суммарно принесли клубу **более 3 500 рублей**. Отсортируйте по убыванию выручки.
