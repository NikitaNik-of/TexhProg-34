# Практическая работа #6: Уровень 2 (Средний / Medium)

## 1. Описание набора данных
В папке вашего варианта (`medium/variant_XX/`) представлены три CSV-файла (разделитель — точка с запятой `;`):

* `hardware_pcs.csv` — каталог компьютеров клуба:
  * `pc_id` — уникальный идентификатор рабочей станции;
  * `pc_number` — номер ПК (`PC-01`, `PC-02`...);
  * `zone_name` — зона посадки (`Standard`, `Bootcamp`, `VIP`, `PS5`);
  * `hourly_rate` — базовый тариф за час аренды (руб.);
  * `gpu` — модель установленной видеокарты;
  * `cpu` — процессор;
  * `ram_gb` — оперативная память (ГБ);
  * `status` — эксплуатационный статус (`Active`, `Maintenance`, `Reserved`).

* `members.csv` — база зарегистрированных клиентов:
  * `member_id` — номер клубной карты;
  * `nickname` — игровой псевдоним;
  * `city` — город регистрации;
  * `email` — электронная почта (часть значений `NULL`);
  * `registered_at` — дата регистрации (`YYYY-MM-DD`);
  * `loyalty_tier` — уровень карты (`Bronze`, `Silver`, `Gold`, `Platinum`);
  * `balance` — депозит на счете (руб.).

* `game_sessions.csv` — журнал игровых сессий:
  * `session_id` — номер сессии;
  * `member_id` — ID игрока (для анонимных визитов без клубной карты значение равно `NULL`);
  * `pc_id` — номер занятого ПК (внешний ключ к `hardware_pcs`);
  * `game_title` — основная запущенная игра;
  * `session_date` — дата и время начала (`YYYY-MM-DD HH:MM:SS`);
  * `hours_played` — продолжительность сессии в часах;
  * `discount_promo` — флаг скидки (1 — скидка 10%, 0 — без скидки);
  * `total_paid` — фактическая оплата аренды с учетом скидки (руб.);
  * `client_rating` — оценка сервиса от 1 до 5 звезд (пропущенные отзывы — `NULL`).

## 2. Задания к выполнению

### Часть 1. Перенос данных в SQL и аудит схемы (CSV → SQLite)
1. Загрузите файлы `hardware_pcs.csv`, `members.csv` и `game_sessions.csv` в Pandas.
2. Подключитесь к базе данных `club_medium.db` через `sqlite3.connect()`.
3. Обязательно активируйте контроль внешних ключей: `conn.execute("PRAGMA foreign_keys = ON;")`.
4. Создайте три таблицы через `CREATE TABLE` с ограничениями `PRIMARY KEY`, `NOT NULL` и внешними ключами:
   * `game_sessions.member_id` ссылается на `members(member_id)`;
   * `game_sessions.pc_id` ссылается на `hardware_pcs(pc_id)`.
5. Импортируйте датафреймы в SQLite методом `.to_sql(..., if_exists='append', index=False)`.
6. Сверьте число строк в каждой таблице через SQL-запрос `COUNT(*)` и функцию Pandas `len(df)`.

### Часть 2. Агрегатный аудит и анализ пропусков
1. **Экономика клуба одной строкой:**  
   Рассчитайте:
   * общее число сессий;

   * среднюю оценку сервиса (`AVG(client_rating)`), округленную до 2 знаков;
   * суммарное число часов игрового времени.
2. **Анализ анонимного потока (`NULL`):**  
   * Найдите долю сессий анонимных гостей (`member_id IS NULL`): их количество, суммарную выручку и средний чек.  
   * Сравните средний чек анонимов со средним чеком зарегистрированных клиентов клуба.
3. **Аудит активности обратной связи:**  
   Посчитайте, сколько клиентов поставили оценку (`COUNT(client_rating)`), сколько воздержались, и процент сессий с оставленными отзывами.

2. **Финансовая состоятельность городов:**  
   По таблице `members` сгруппируйте клиентов по городам (`city`). Рассчитайте число клиентов, средний баланс и максимальный баланс. Отфильтруйте города со средним балансом **не менее 1 000 рублей**.
3. **Сквозной конвейер (WHERE + GROUP BY + HAVING):**  
   Рассмотрите сессии **без скидки** (`discount_promo = 0`) длительностью **от 2 часов и более**. Сгруппируйте их по играм и оставьте игры со средней стоимостью сессии **более 500 рублей**. Передайте пороговые числа через параметры `?`.
